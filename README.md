# Gmail sender

A small Python script that constructs an email message and sends it through Gmail SMTP over TLS.

## Quick start

Configure the sender, recipient, subject, body, and Gmail app password in your local copy of `main.py`, then run `python main.py`. Keep credentials out of commits. Python standard-library modules are sufficient.
